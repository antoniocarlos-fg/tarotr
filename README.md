# tarotr

A desktop tarot reading application built with **Tauri**, **React**, **TypeScript** and **Tailwind CSS**.

> 🚧 **Work in Progress** — The project is currently in an early development stage. The core functionality is being implemented before the final visual design and pixel-art assets.

> 🇧🇷 **Portuguese only for now** — The application currently only supports Portuguese (pt-BR). Localization/i18n is planned for the future.

## About

tarotr is a personal project focused on creating a simple and interactive tarot reading experience as a desktop application.

The current version already has the basic application structure and functionality, while the visual identity, card artwork and additional features are still being developed.

## Tech Stack

* [Tauri](https://tauri.app/) — Desktop application framework
* React — User interface
* TypeScript — Application logic
* Tailwind CSS — Styling
* Vite — Frontend tooling

## Development

Clone the repository and install the dependencies:

```bash
git clone https://github.com/antoniocarlos-fg/tarotr.git
cd tarotr
npm install
```

Run the application in development mode:

```bash
npm run tauri dev
```
